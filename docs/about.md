# About

Written by Mantas Valantinavicius, a measurement scientist and laboratory
quality professional. The handbook brings lab-quality habits (traceable
inputs, stated uncertainty, records an auditor can follow) to sustainability
reporting.

Companion to the [Lab Accreditation Handbook](https://mantas123456.github.io/lab-accreditation-handbook/).

## Review status

Version 1.0 was **self-reviewed** by the author, reading each track as a
CBAM customs specialist, a GHG verifier and a CSRD limited-assurance
provider would, and the key facts were re-read in the Official Journal.
Version 1.1 adds C10 (EU Taxonomy KPIs) and extends CB7, with the facts
read in the Official Journal in the same way. The handbook has **not yet
been reviewed by an external practitioner**, so every page is marked as a
draft. A page will be marked reviewed only after an external
practitioner has reviewed it.

## PDF edition and citation

Each release on GitHub has a [PDF edition](https://github.com/mantas123456/esg-workflows-handbook/releases/latest) of the whole handbook and
a ZIP of the templates. Each release is also archived on Zenodo. To cite
the handbook, use its DOI
[10.5281/zenodo.24423578](https://doi.org/10.5281/zenodo.24423578), which
always points to the latest version (each release also has its own DOI), or
the [citation file](https://github.com/mantas123456/esg-workflows-handbook/blob/main/CITATION.cff).
