# Roadmap

The handbook grows in versions. Each one is complete on its own. The order
follows the hard deadlines: CBAM first (first declaration due 30 Sep 2027),
CSRD last (companies still in scope first report on FY2027).

| Version | Target | Adds | Status |
|---|---|---|---|
| **0.1 Skeleton** | Dec 2026 | Site, workflow map, chapter format, regulation tracker, triage, evidence locker, data reuse map | **Done** (20 Nov 2026) |
| **0.2 CBAM** | Feb 2027 | CB1-CB10, threshold checker, embedded-emissions calculator, supplier request and declaration templates | **Done** (20 Nov 2026), pages in draft |
| **0.3 Scope 3** | Apr 2027 | S1-S9, data quality and uncertainty, screening tool, inventory workbook | **Done** (20 Nov 2026), pages in draft |
| **0.4 VSME** | Jun 2027 | V1-V6, Basic module workbook, questionnaire playbook | **Done** (20 Nov 2026), pages in draft |
| **0.5 CSRD / ESRS** | Sep 2027 | C1-C9 on the simplified ESRS, double materiality workbook, gap analysis | **Done** (20 Nov 2026), pages in draft |
| **0.6 Tools polish** | Oct 2027 | Tested browser tools, template pack built in CI, change-log process | Planned |
| 1.0 Reviewed | Dec 2027 | Practitioner review, PDF edition, citable DOI | Planned |

See the [changelog](changelog.md) for what changed in each release.
