# 1. Goods and quantities (CB1)

| ☐ | Check | Done by / date |
|---|---|---|
| ☐ | Import list for the year is complete and matches the customs declarations | |
| ☐ | Every CN code checked against Annex I to the CBAM Regulation | |
| ☐ | Goods originating in Annex III countries and territories (Iceland, Liechtenstein, Norway, Switzerland and five territories) left out | |
| ☐ | Total quantity per type of goods calculated | |
| ☐ | Hydrogen and electricity listed separately (no threshold applies) | |

# 2. Authorisation (CB2)

| ☐ | Check | Done by / date |
|---|---|---|
| ☐ | Authorised CBAM declarant status registered in the CBAM registry | |
| ☐ | Customs broker uses the authorisation on declarations for CBAM goods | |

# 3. Embedded emissions (CB3 to CB5)

| ☐ | Check | Done by / date |
|---|---|---|
| ☐ | For each installation: actual (verified) or default values decided and recorded | |
| ☐ | Actual data covers the calendar year of production | |
| ☐ | Indirect emissions included only for cement and fertilisers | |
| ☐ | Precursors included, using mass consumed; EU-origin precursors listed at zero | |
| ☐ | Default values taken from Implementing Regulation (EU) 2025/2621 (as corrected), with the mark-up for the year of import | |
| ☐ | Embedded emissions per CN code and in total calculated | |

# 4. Verification (CB6)

| ☐ | Check | Done by / date |
|---|---|---|
| ☐ | A verification report for every installation using actual values | |
| ☐ | Verifier accredited for CBAM by an EU national accreditation body, valid on the report date | |
| ☐ | Report covers the installation, the CN codes and the production year | |
| ☐ | Figures in the report match the figures used | |

| ☐ | If yes: evidence independently certified | |
| ☐ | If yes: conversion into certificates follows Implementing Regulation (EU) 2026/2498 | |

# 6. Certificates (CB8)

| ☐ | Check | Done by / date |
|---|---|---|
| ☐ | Free allocation adjustment calculated | |
| ☐ | Certificates to surrender = embedded emissions − adjustment − carbon-price reduction (not below zero) | |
| ☐ | Enough certificates on the account in the CBAM registry | |
| ☐ | Quarterly holding of at least 50% kept during the year (from 2027) | |
